# Massarat Bano Kaifi — Healing Website

Prototype website for Massarat Bano Kaifi, offering **Cord Cutting** and **Akashic Records** sessions.

## Contents

A single static page (`index.html`) with:

- **Services** — Cord Cutting and Akashic Records, each with a description, who it helps, what to expect, and session length
- **About** — bio for Massarat (photo placeholder)
- **Contact** — form with Name, Email, Phone, Service dropdown, and Description, with client-side validation

## Preview

Open `index.html` in a browser. No build step needed.
